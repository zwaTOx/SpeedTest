# SpeedTest

**SpeedTest** — небольшой консольный проект на Python для проверки скорости загрузки данных по HTTP(S). Программа последовательно скачивает тестовый файл, выводит результат каждой попытки и формирует итоговую статистику по успешным загрузкам и ошибкам.

## Возможности

- Несколько последовательных загрузок одного тестового файла.
- Настройка количества попыток и тайм-аута.
- Передача параметра отключения кеширования в загрузчик.
- Вывод результата каждой попытки и общей статистики.
- Обработка сетевых и других ожидаемых ошибок без остановки всего теста.
- Код завершения `0`, если все попытки успешны, и `1`, если возникли ошибки.



## Структура проекта

```text
SpeedTest/
├── main.py             # Запуск тестирования и настройки
└── src/
    ├── downloader.py   # Загрузка файла и результат загрузки
    ├── stats.py        # Расчёт итоговой статистики
    └── display.py      # Форматированный вывод в консоль
```



## Требования

- Python 3.
- Доступ к интернету для скачивания тестового файла.

Если в модулях `src/` используются сторонние библиотеки, их необходимо установить отдельно. В приведённом `main.py` используются только импорты из стандартной библиотеки и локальных модулей проекта.

## Запуск

1. Откройте терминал в корневой папке проекта `SpeedTest` (там, где лежит `main.py`).
2. Запустите программу:

```bash
python main.py
```

После запуска программа выполнит заданное количество загрузок, выведет результаты попыток и затем общую статистику. Если отдельная попытка завершится ошибкой, тест продолжится.

## Настройки

Параметры задаются в начале файла `main.py`:

```python
URL = "https://cachefly.cachefly.net/10mb.test"
COUNT = 10
TIMEOUT = 60
```


| Параметр  | Значение по умолчанию                     | Назначение                        |
| --------- | ----------------------------------------- | --------------------------------- |
| `URL`     | `https://cachefly.cachefly.net/10mb.test` | Адрес файла для тестирования      |
| `COUNT`   | `10`                                      | Количество попыток загрузки       |
| `TIMEOUT` | `60`                                      | Тайм-аут одной попытки в секундах |




## Как работает программа

1. `main.py` вызывает `print_header()` для вывода параметров теста.
2. Для каждой попытки вызывается `download()` из `src/downloader.py`.
3. Успешный результат добавляется в список `results` и выводится через `print_result()`.
4. Ошибки `URLError`, `OSError`, `HTTPException` и `ValueError` учитываются в счётчике `errors`.
5. Если успешных попыток нет, программа сообщает об ошибке и завершает работу с кодом `1`.
6. В остальных случаях `calculate_stats(results, errors)` рассчитывает сводные показатели, а `print_summary()` выводит их на экран.



## Примечания

- Результаты зависят от скорости соединения, загрузки сервера и сетевых условий.
- Тест скачивает файл указанного размера повторно, поэтому расходует интернет-трафик.
- Если используете другой тестовый URL, убедитесь, что сервер разрешает скачивание файла. И не возникает 429 ошибка.
